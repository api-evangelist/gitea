We are excited to announce the release of **Gitea 28.1.0**, the first maintenance release for the 28 series. It contains security fixes and fixes for regressions reported after 28.0.0, including pushes to protected branches from Actions, the npm registry, and MySQL, MariaDB and MSSQL transactions. We strongly recommend that all users upgrade as soon as possible.
