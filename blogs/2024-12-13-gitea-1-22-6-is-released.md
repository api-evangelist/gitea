We are excited to announce the release of **Gitea version 1.22.6**. This is an urgent update because the security bug fixes in version [1.22.5](https://blog.gitea.com/release-of-1.22.5) released yesterday, which only addressed the Golang crypto library upgrade, are not sufficient. We strongly recommend all users upgrade to the latest version as soon as possible to ensure full protection.
