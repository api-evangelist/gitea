We are excited to announce the release of **Gitea 1.27.3**, the third patch release for the 1.27 series. It contains a large batch of security fixes covering Gitea Actions, the API, the package registry and repository migration, alongside bug fixes for Actions, packages and the UI. We strongly recommend that all users upgrade as soon as possible.
