:::warning **Gitea for VS Code is currently unavailable from the Visual Studio Marketplace.** We are working with Microsoft to make the extension available again. ::: We are happy to announce the first release of **Gitea for VS Code**. Gitea Actions, pull requests, and repository settings now live in the editor: workflow runs and job logs, native diffs and reviews, artifacts, secrets, and variables, without switching to the browser for every check.
